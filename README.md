# BASIC Community Future Labs

Static five-page site: `index.html`, `about.html`, `programmes.html`, `enquiry.html`, `contact.html` (+ `404.html`).

## Deploy
- **Netlify:** drag this whole folder onto app.netlify.com/drop.
- **GitHub Pages:** push the folder to a repo, then Settings > Pages > deploy from `main` / root.

## Before going live
- Replace the placeholder images in `images/` with your photos (same names, `.jpg`), then change `.svg` to `.jpg` in `index.html`.
- Change `basiccommunity.org` in `robots.txt`, `sitemap.xml` and the contact details to your real domain and email.
