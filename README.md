# BASIC Community Future Labs

A responsive static website for BASIC Community Future Labs, a fictional South African community-learning organisation with labs in Johannesburg and Durban.

## Pages and features
- `index.html` — home page, statistics, programmes gallery and animations
- `about.html` — organisation, FAQ and accessibility content
- `programmes.html` — searchable, filterable and sortable programme directory
- `enquiry.html` — volunteer, sponsorship and partnership enquiries with calculated responses
- `contact.html` — validated contact form, Leaflet maps and directions

The site also includes an accordion, tabs, modal, keyboard-operated lightbox, responsive navigation, reveal animations, dynamic programme data and form validation.

## Run locally
1. Clone or download the repository.
2. Open `index.html` directly, or serve the folder with any local web server.
3. Example using VS Code: run Live Server on `index.html`.

## Deployment
The `main` branch is deployed with GitHub Pages from `/ (root)`. Changes pushed to `main` should update the published site.
